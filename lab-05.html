Necessary Concepts

Understand the simulation workflow before beginning the tasks.

Circuit Simulation

Multisim represents electrical components using mathematical models and predicts circuit behaviour before a physical circuit is assembled. A simulation is useful for checking calculations, observing signals and testing changes quickly. Simulated results may differ from physical readings because virtual components can be ideal while real components have tolerance, temperature effects, wiring resistance and instrument limitations.

Basic Multisim Workflow

  1. Create a new design and save it with a meaningful filename.
  2. Place the required sources, resistors, ground and instruments.
  3. Open each component and enter the required value.
  4. Arrange the schematic neatly and connect the components with wires.
  5. Check all junctions and instrument connections.
  6. Run the simulation and observe the readings.
  7. Stop the simulation before changing the circuit structure.
  8. Save the completed design and capture the required screenshots.

Ground Reference

A SPICE simulation requires a reference node identified as ground or node zero. The ground establishes the zero-voltage reference used for circuit calculations and oscilloscope measurements. A missing or incorrectly connected ground may prevent the circuit from simulating correctly.

Virtual Measurements

Connect a voltmeter or oscilloscope channel across the two points whose voltage is required. Insert an ammeter in series with the branch whose current is required. The sign of a reading depends on the selected terminal polarity. Avoid connecting an ammeter directly across a source.

Function Generator and Oscilloscope

The function generator supplies a selected waveform, amplitude, frequency and offset. The oscilloscope displays voltage against time. Connect Channel A to the circuit input and Channel B to the selected output node, with both channel reference terminals connected to circuit ground. Adjust the voltage scale and time scale until both traces are clearly visible.

Common Problems

  • Missing ground reference
  • Open or overlapping wires that are not electrically connected
  • Incorrect component value or unit prefix
  • Ammeter connected in parallel
  • Voltmeter connected in series
  • Oscilloscope reference connected to the wrong node
  • Simulation left running while the circuit is being modified

Important: Simulation does not replace safe laboratory practice. Confirm component ratings and instrument connections before constructing the same circuit physically.

Part B: Function Generator and Oscilloscope

  1. Stop the simulation and replace the DC source with the Multisim function generator.
  2. Select a sine wave, set the frequency to 1 kHz, amplitude to 5 V and offset to 0 V.
  3. Connect oscilloscope Channel A across the circuit input.
  4. Connect oscilloscope Channel B across the selected output resistor.
  5. Connect both oscilloscope reference terminals to circuit ground.
  6. Run the simulation and adjust the voltage and time scales until both traces are clearly visible.
  7. Measure the peak-to-peak voltage, period and frequency of both signals.
  8. Calculate the voltage ratio Vout/Vin.
  9. Compare the simulated voltage ratio with the theoretical voltage-divider ratio.
  10. Capture a screenshot showing both oscilloscope traces.
