ELECTRIC CIRCUITS LABORATORY MANUAL

Open electric-circuits-labs.html in your browser. It contains Background and
Labs 01 to 08. All HTML, CSS and JavaScript are in that one editable HTML file.
Keep the supplied assets folder and uet-icon.png beside the HTML file.
Embedded pictures from the original files have been extracted as normal images.

NAVIGATION
The lab list stays on the left on desktop screens. On smaller screens,
select Labs to open the same navigation from the left. Print controls are
in the sidebar. Navigation is hidden when printing.
To resize the desktop sidebar, edit --manual-sidebar-width in the shared CSS.

EDITING
Find the labelled LAB START and LAB END comments to edit a lab.
Find the lab's labelled STYLES block to edit its appearance.
Find FUTURE LABS INSERTION POINT to insert future approved lab sections.
The automatic navigation reads each section's data-label and main heading.
Use lab-prefixed IDs so links and worksheet labels remain unique.

EQUATIONS AND NOTATION (APPLIES TO FUTURE LABS)
Keep equations on separate lines. Use native MathML with display="block".
Use <mfrac> for fractions: its first child is the numerator and its second
child is the denominator. Native MathML requires no external math script.
Use <msub> for subscripts and <msup> for powers inside MathML. Use <sub> and
<sup> for variables in normal text and tables. Keep variable markup attached
to its text. Each display equation has an editable source comment above it.
Keep HTML indented; put blocks, table rows and table cells on separate lines.
Preserve approved content and match the existing theme for every future lab.

FINALIZED SOURCE NOTE
Lab 08's graph instruction says Ps versus RL. Its maximum-load-power equations
and result table use PL. This wording is preserved from the finalized Word file.
